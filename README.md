# JPMorgan Stock Analysis 📈

## Overview

This project analyzes JPMorgan Chase (JPM) stock performance over a one-year period using Python and historical market data.

I created this project to practice using Python for financial analysis and to better understand stock returns, volatility, moving averages, and benchmark comparisons.

## Analysis

The project calculates:

- One-year stock return
- 52-week high and low
- Annualized volatility
- 50-day moving average
- 200-day moving average
- Performance compared with the S&P 500

## Results

| Metric | Result |
|---|---:|
| Starting Price | $306.87 |
| Ending Price | $352.04 |
| JPM 1-Year Return | 14.72% |
| S&P 500 Return | 16.64% |
| Difference vs. S&P 500 | -1.92 percentage points |
| 52-Week High | $365.18 |
| 52-Week Low | $280.14 |
| Annualized Volatility | 22.22% |

## Key Takeaways

During the period analyzed, JPM increased from $306.87 to $352.04, producing a return of 14.72%.

The S&P 500 returned 16.64% during the same period, meaning JPM underperformed the benchmark by 1.92 percentage points.

JPM reached a high of $365.18 and a low of $280.14 during the period. Its annualized volatility was 22.22%, which helps measure the amount of variation in the stock's returns.

The 50-day and 200-day moving averages were also used to better understand short-term and longer-term price trends.
